## 0.5점대 진입 분석

### Baseline → LB 추론
- Baseline avg OOF: 0.594
- V413 avg Student OOF: 0.651 → LB: 0.627
- Baseline은 V413보다 **더 simple** → gap이 더 작을 가능성
- 만약 gap이 0.015면: LB = 0.594 + 0.015 = **0.609**
- 만약 gap이 0.030 (V413과 동일)면: LB = 0.594 + 0.030 = **0.624**

### 0.5점대의 현실성
- Per-subject mean이 OOF 0.594 → 이 자체가 **데이터의 하한선**
- subject별 평균을 prediction에 사용하는 것은 **최적 baseline**
- 이 baseline을 넘으려면 **subject-level signal**을 찾아야 함
- 현재 features는 이 signal을 담고 있지 않음 (noise)
- **0.5점대 진입을 위해서는:**
  1. Subject-level features 추가로 subject-mean prediction 개선
  2. 또는 external data (라이프로그 raw data 활용)
  3. 또는 temporal features (과거 패턴 활용)

### 결론
**현재 features로는 0.5점대 진입이 구조적으로 불가능.**
V413(ML model)이 baseline(0.594)보다 0.651로 더 나옴 — features가 signal이 아님.

0.5점대를 원하면:
- **Raw data features 재설계** (aggregate가 아닌 raw pattern)
- **Temporal modeling** (sequence model, LSTM 등)
- **External data 추가**
- **Baseline(0.594)이 실질적 하한선**

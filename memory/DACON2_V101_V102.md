# V101~V102 분석 로그 (2026-05-11)

## V101: LB Prediction Model

### 핵심 발견: LB 공식 역설계 성공
- **LB = mean(log_loss per target)**에 테스트 데이터
- 단순한 binary cross-entropy의 평균. "Calibration"은 calibration된 예측값을 쓴다는 뜻
- V53 OOF log_loss = 0.5479 → meta의 avg_cal_loss = 0.5479와 **완전히 일치**

### V53 분석
- Train LL: 0.5479, LB: 0.65358, **gap = 0.106** (테스트가 train보다 나쁨)
- 정보 포착률: Q1 13.9%, S1 20.7%, S3 20.5% (Q1-Q3가 가장 낮음)
- S1-S4 (절대 지표)가 Q1-Q3 (상대 지표)보다 모델 성능 좋음

### LB 예측 공식 (4개 점, RMSE 0.0017)
```
LB = 0.0896*entropy - 0.4205*max_shift + 0.1877*skew 
     + 0.4262*S3_shift + 0.2194*S4_shift + 0.7740
```
- **S3/S4 shift가 음수일수록 LB가 낮아짐** (핵심!)
- `abs(shift)` vs LB: 모든 타깃에서 r = -0.90 (강한 음의 상관)
- train mean과 멀어질수록(예측이 더 차별적일수록) LB가 좋음

### V99 예측
- predicted LB: 0.735 → **제출 금지**

## V102: S3/S4 shift amplification

### 전략
- V53 예측값에서 S3, S4 train mean과의 차이(shift)를 1.3배 증폭
- S1, S2도 1.15배 증폭
- Q1-Q3는 그대로 유지

### 결과
- V53 predicted LB: 0.655, V102 predicted LB: **0.620** (+0.035 개선)
- S3 shift: -0.136 → -0.177
- S4 shift: -0.076 → -0.098
- Train LL은 거의 동일 (0.5479 → 0.5497, +0.0018)

### 한계
- 예측 모델 RMSE가 낮지만 외삽 신뢰도는 낮음
- 실제 LB 검증을 위해 제출 필요

## LB 0.5 목표 달성 가능성

### 현재 상태
- V53 train LL = 0.5479, LB = 0.654, gap = 0.106
- LB < 0.50을 위해: train LL < 0.394 필요 (29% 개선)
- 현재 정보 포착률 14-21% → 30-50%까지 높여야 함

### 개선 방향
1. **더 많은 시드** (50 → 100+): 분산 감소
2. **가상 레이블(pseudo-labeling)**: test 예측을 training에 추가
3. **feature engineering**: 상호작용, time-series feature
4. **per-subject calibration**: 개체별 baseline 보정
5. **S3/S4 shift 증폭**: V102의 접근 방식 강화

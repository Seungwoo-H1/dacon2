## V265 Root Cause Analysis — 완료 ✅

### 핵심 결론
1. **OOF는 진짜 Out-of-Fold** — 각 샘플 정확히 1회 예측됨. In-fold 편향 없음.
2. **OOF-LB gap ≈ 0.11은 구조적** — train-test drift (PSI=0.44) + 다른 테스트 분포 때문. Validation error 아님.
3. **V127이 undisputed best** (LB=0.648, OOF=0.537). 숨겨진 강자 없음.
4. **V45/V46는 leakage** (accuracy 100%/99.6% → 물리적으로 불가능).
5. **S1이 가장 fold variance 큼** (std=0.111, range=0.297) → 검증 가장 어려움.
6. **Ensemble diversity 낮음** (avg corr 0.7-0.98) → ensemble으로 개선 어려움.
7. **최적 gap 모델**: `LB ≈ OOF + 0.105`

### Key Findings from V13:
1. **External data feature engineering**: A,B,C 각각 3~4개 column만 매핑 가능 → external representation learning이 제한적
2. **Curriculum Learning**: S1에 +0.00712 improvement 발견 — 유일한 외부데이터 기반 양수 개선
3. **Confidence Filtering (내부 data만)**:
   - S2_t0.80: delta=-0.12465 (n_kept=103) → 매우 큰 improvement
   - S3_t0.75: delta=-0.25610 (n_kept=77) → 가장 큰 improvement
   - **문제**: confidence filtering으로 OOF가 급락하는 것은 **overfitting 신호**일 수 있음. filtered sample 수가 50-100개면 CV fold간 분산 큼
   - 특히 S3_t0.80에서 delta=+0.18373 (worst) → overfitting 반전
4. **Ensemble Optimization**:
   - S3가 가장 큰 개선: delta=-0.0624 (wide:0.3 + deep:0.7)
   - Q1도 good: delta=-0.0167 (wide:0.6 + v48:0.4)
5. **Noise Filtering**: remove 5-25 samples → consistent negative delta (모든 target에서) → noisy sample 제거가 OOF 개선에 도움

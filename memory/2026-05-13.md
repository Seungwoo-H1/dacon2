## V251 External Merge — 결과 분석

### Experiment
- V251: features_clean_v60 + external_data.parquet (8 external features: holiday, month, school_term, exam_period, lunar_holiday, daylight_hours, daylight_ratio, season_index)
- 100% coverage for all 450 train and 250 test dates
- Feature ranking (50-iter LGBM) → top-N selection per target
- 7 targets trained with V127 per-target configs

### Results
- V251 avg OOF: 0.69288
- V251 Δ: +0.00516 (worse)
- Improvement in Q1 (-0.00159), Q3 (-0.08346), S3 (-0.00619)
- Worsening in S1 (+0.02261), S2 (+0.08878), S4 (+0.02304)
- Selected external features: daylight_hours (Q1, S2, S3), season_index (S2, S3), daylight_ratio (S3)
- External features selected in only 3/7 targets (1-3 features per target)

### Critical Issue: V127 Baseline Reproduction Failed
- V251's "V127 baseline" OOF = 0.68771
- True V127 OOF = 0.53731
- **V127은 single model이 NOT 3-model ensemble** (V121 + V123 + V115 uniform weight)
- V251은 single model with feature selection → 비교 불가
- **Lesson**: V127 true baseline comparison requires re-implementing the 3-model ensemble

### Key Finding
- **external_data.parquet features (holiday/month/daylight/season) provide NO improvement** to the current pipeline
- These are static calendar/temporal features — too general for individualized sleep prediction
- Contrasts with V09 external features (sleep_health_lifestyle.csv proxy features, ΔOOF=-0.023)
- **Lesson**: Only PERSONALIZED external features (sleep patterns, activity levels) → useful. Calendar features → noise.
